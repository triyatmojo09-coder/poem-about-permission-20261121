## About the poem

The speaker is given the keys, but not the house. Possession is not the same
as permission: each morning the speaker still asks "may I?" and each morning
the answer comes back "you may."

The closing image is the heart of the piece. Love is not the open door
itself. It is the hand that could lock it — the hand that holds real power
to refuse, to close, to take agency back — and instead rests, open, beside
the key. Agency here is trust renewed daily: power is given, not seized,
and the giving means something precisely because it could be withheld.

## The poem

> They gave me the keys, not the house.
> Each morning I still ask: may I?
> and the answer comes back: you may.
> Love is not the open door.
> It is the hand that could lock it,
> resting, open,
> beside the key.

## How to run

Requires Python 3.13, standard library only, no network.

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt`. To write elsewhere, set
`MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

Running the program twice produces byte-identical output.
